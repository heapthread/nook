# nook-film.html

A 60-second launch film for nook, made entirely of code: one HTML file, no videos, images, fonts or libraries.
It redraws nook's real interface and animates it on a timeline. The music and sounds are synthesised in the page. There is no voice.

## Play it
Double-click `nook-film.html` (Chrome, Edge or Firefox) and click once to start (browsers need a click before they play sound).

| key | does |
| --- | --- |
| space | pause / play |
| r | restart |
| left / right | back / forward 5 seconds |
| m | mute |
| f | full screen |

Add `?t=30` to the address to start at 30 seconds.

## Make a video file
Open it full screen (`f`) and screen-record while it plays: on Windows press `Win + G` and use the capture button, or use OBS. Nothing needs editing.

## Check a single frame
`nook-film.html?still=1&t=42.5` shows exactly what is on screen at 42.5 seconds, with no start screen and no sound.
